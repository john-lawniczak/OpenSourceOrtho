# USER_ONE acquisition photos

Contributor-supplied photographs added on 2026-11-12 for the
[how-to guide](../../../../HOW_TO.md#user_one-photo-walkthrough).
They document materials, impressions, stone casts, and a turntable setup.
The filenames describe visible content; their sequence is for presentation.
Capture dates and association with a particular scan visit are not established here.

The contributor requested publication, descriptive renaming, and metadata removal.
All 11 JPEGs were oriented before removing metadata, converted to sRGB pixels,
and resized to a maximum 1600-pixel edge for documentation. EXIF (including GPS),
XMP, IPTC, ICC profiles, embedded previews, comments, and application metadata
are absent from these exports. No camera identifiers or original capture timestamps
are retained. Full-resolution sanitized versions remain with the contributor.

These images document this case's acquisition process, not validated impression
or casting instructions. Equipment packaging does not constitute an endorsement.
The casts shown together are a display arrangement, not a measured bite registration.
See the [scan acquisition guide](../../../../GETTING_YOUR_TEETH_SCANNED.md)
for acquisition options and limitations.
